# Header artwork

`header.png` was generated using the built-in ImageGen tool on October 17, 2026. It is branding artwork; the screenshots in `../screenshots` are actual simulator captures.

Prompt:

> Wide GitHub README header for 72H Fasting Contest, approximately 3:1. Pale cool grey background, electric iOS blue accents, deep charcoal typography. Large text: “72H FASTING” then “CONTEST”. Subtitle: “Track your progress. Challenge together.” A sculptural blue 72-hour timer ring with a blue trophy and six milestone dots. Restrained dimensional materials, soft shadows, generous spacing. No phone frames, fabricated UI or participant data, medical or weight-loss claims, watermarks, or Apple logos.
